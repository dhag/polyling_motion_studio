解説 4×4 行列・クオータニオン・3×3 ではダメな理由

1. 4×4 行列とは何か

3D の点 p = (x, y, z) に対し、回転と平行移動を一度に作用させるための行列です。 点を 同次座標 (x, y, z, 1) として 4 成分で書き、それに 4×4 の行列を掛けます。 構造はいつも次の形をしています。

M = [ R3×3 | t3×1 ]
    [ 0 0 0 |  1 ]

左上 3×3 が 回転（とスケール）、右上 3×1 が 平行移動、末行は必ず (0, 0, 0, 1) です。 この形にしておくと、親子の連結は単に行列の積になります。

M_world(子) = M_world(親) · M_local(子)

本デモのチェーンは、まさにこの式を root から順番に掛け算しているだけです。

2. なぜ 3 次元なのに 3×3 ではダメか

3×3 行列で書ける変換は 線形変換 だけです。回転・スケール・せん断は線形ですが、 平行移動 v′ = v + t は 線形ではありません。なぜなら線形変換は必ず原点を原点に写すのに、 平行移動は原点を t だけ動かしてしまうからです。

線形でないと何が困るのか。合成が行列の積で書けなくなる のが致命的です。 もし回転 R と平行移動 t を 3×3 行列と別ベクトルで持ち回ると、子の世界座標を求める式は

p_world = R_親 (R_子 · p + t_子) + t_親

のようにネストが深くなり、ボーンが 10 段になれば 10 重の入れ子になります。 ここで 同次座標 を導入し、ベクトルに余分な 1 を付け足して 4 次元として扱うと、 平行移動も 4×4 行列の積として表現できるようになります。

[ x′ ] [ R  t ] [ x ]
[ y′ ] = [ R  t ] [ y ]
[ z′ ] [ R  t ] [ z ]
[ 1  ] [ 0  1 ] [ 1 ]

結果、ネストした入れ子は M_world = M₁ · M₂ · … · Mₙ という素直な行列積一発になり、 GPU のシェーダや骨スキニングが極めて簡潔になります。 4×4 にする目的は次元を増やすことではなく、平行移動を「行列の積」の言語に押し込めることです。

補足：透視投影もこの 4×4 同次行列で表現できるので、CG パイプライン全体がたった一種類の行列で統一されるという副産物もあります。

3. クオータニオンとは何か

3D 回転を 4 つの実数 q = (w, x, y, z) で表したものです。 単位ベクトル n = (nx, ny, nz) の周りに角度 θ だけ回す回転は、

q = ( cos(θ/2),  nx·sin(θ/2),  ny·sin(θ/2),  nz·sin(θ/2) )

と書けます。常に |q| = 1 になるように正規化します。 回転の合成は クオータニオン積 q₁·q₂ で表され、これが本デモの 3×3 回転行列に変換されて 4×4 に組み込まれます。

3D 回転は本質的には自由度 3 ですが、あえて 4 成分で持つことには理由があります。

  • ジンバルロックが起きない：オイラー角（XYZ の 3 つの角）は特定の姿勢で 1 軸が消失する病的特異点を持ちますが、クオータニオンは球面上の点として連続に振る舞います。
  • 滑らかな補間ができる：2 つの姿勢の間を最短経路で繋ぐ Slerp（球面線形補間）は、行列ではうまく書けませんがクオータニオンでは自然に書けます。アニメーションのキーフレーム補間が綺麗になります。
  • 軽くて数値的に安定：回転行列は 9 個の値で 6 個の直交拘束、クオータニオンは 4 個の値で 1 個の単位拘束。誤差が溜まっても q ← q / |q| で 1 行で再正規化できます。
  • 姿勢の差分が表現しやすい：q_差 = q_目標 · q_現在−1 のように、回転の引き算が定義できます。

欠点は人間が値を直感的に読めないことです。だからこの教材ではスライダ入力をオイラー角（°）にしておき、 内部で q = q_Y · q_X · q_Z（Unity の順序）に変換しています。スライダを動かしながら q の 4 値と その |q| が常に 1 を保つ様子を眺めると、クオータニオンが「単位 4 次元ベクトル」として 3D 回転を表現しているのが体感できます。

4. このデモで何が見えるか

  • 親子伝播：上腕を回すと、ひじ・手首の ローカル 行列は 1 ビットも変わらない のに ワールド 行列は変わる。これは「子は親のワールドに自分のローカルを積むだけ」だからで、上に表示される親のワールドとローカルを見比べると、ワールドの中身が 親.world · local ぴったりに一致しているのが確認できます。
  • 非対称性：逆にひじを回しても、上腕は微動だにしません。子の変換は親に影響しないからです。
  • 合成チェーン：root（Hips）から選択ボーンまで、ローカル行列を順に掛けた積がそのままワールド行列になります。チェーン表示と各行列を見比べてください。
